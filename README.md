# el_vse_lab
Рабочее место сотрудников лабораторий ВСЭ

В репозитории находятся рабочие HTML-макеты электронной лаборатории и локальный каталог Storybook.

## Storybook

```powershell
npm.cmd ci
npm.cmd run storybook
```

После запуска откройте http://localhost:6006. Окно терминала должно оставаться открытым.

Инструкция для аналитика и порядок добавления первых компонентов: [STORYBOOK.md](STORYBOOK.md).

Проверка сборки каталога: `npm.cmd run build-storybook`.

Первый набор компонентов выделен из `login.html`: поле (включая пароль), кнопка, ссылка, форма и полный экран. Страница входа использует тот же код, что и Storybook. Другие страницы пока не перенесены.

Описание API: [components/auth/README.md](components/auth/README.md). Проверки поведения и доступности после сборки: `npm.cmd run test:ui` (используется установленный Google Chrome).
