# Три концепции карточек принятых партий

Открыть `index.html` в браузере: три работающие компоновки переключаются вкладками. Каждая также доступна отдельно в `concept-1.html`, `concept-2.html` и `concept-3.html`.

## Что сравнивать

1. **Единый паспорт.** Данные партии слева; номер, результат, дата, специалист, лаборатория, источник результата и стоимость ВСЭ собраны справа. Заголовок экспертизы подчёркнут, а отдельная кнопка открывает её карточку. Сверка раскрывается, повторные осмотры доступны в окне.
2. **Рабочий реестр.** Компактные строки с хозяйством, продукцией, весом и переходом к ВСЭ. Стрелка раскрывает дополнительные сведения. ВСЭ №882 из другой лаборатории раскрыта при первом открытии для сравнения. Остальные строки свёрнуты.
3. **Карточки экспертиз.** Сетка самостоятельных карточек с экспертизой в качестве главного объекта. Основная область карточки — ссылка на ВСЭ. Автор, дата и лаборатория доступны в быстром просмотре в окне. В дополнительном меню доступны сверка и повторные осмотры.

## Данные и переходы

Во всех концепциях используется один набор из `arrivals-accepted.html`: ВСЭ №168, №169 и №882. Источник данных — `data.js`. Номер, результат, время, специалист и лаборатория сохранены, включая Раису Мухаметшину и Лабораторию ВСЭ №3 г. Набережные Челны для №882.

Существующие `vse-view*.html` показывают другие экспертизы. Поэтому ссылка прототипа ведёт в `vse-card.html?id=...`, который отображает именно выбранную запись. Показатели лабораторных исследований не добавлены: в исходных карточках списка они отсутствуют. Страница возврата сохраняет выбранную концепцию, поиск и фильтр. Эти файлы — изолированные прототипы для выбора структуры карточки.

## Компоненты

Bootstrap 5.3.8: Card, Button, Badge, Collapse/Accordion, Dropdown, Modal, Nav/Tab. Скомпилированные CSS и JS сохранены в `vendor/`; интернет для открытия прототипов не нужен. При скачивании SHA-384 проверен по хешам официальной страницы Bootstrap. Лицензия — `vendor/LICENSE-bootstrap.txt`.

Визуальные токены и адаптивные варианты живут в `concepts.css`. Поведение карточек, фильтров и общего окна живёт в `concepts.js`. Новая продукционная дизайн-система не зафиксирована до выбора концепции.

## Проверка

144 проверки DOM прошли: номера переходов и содержимое экрана ВСЭ, единое размещение данных в первом варианте, поиск по специалисту, сброс поиска, фильтр результата, пустой список, Bootstrap Collapse/Accordion/Tab/Modal, закрытие по Escape, возврат фокуса и восстановление доступности фоновой страницы. Команда: `node ../tmp/accepted-concept-check/check.cjs` из этой папки или `node tmp/accepted-concept-check/check.cjs` из корня проекта.

Все пять HTML-страниц проверены на уникальные ID и существование локальных файлов по ссылкам. JavaScript прошёл `node --check`.

Строгий статический аудит сохранён в `../tmp/accepted-concept-check/premium-audit.json`. Для авторских файлов он выдаёт 33 `affordance.actionless-button`: сканер распознаёт только обработчики внутри HTML и не связывает кнопки с Bootstrap `data-bs-*` и внешними обработчиками JS. Эти действия проверены в тестах DOM. Обработчики-заглушки ради прохождения сканера не добавлялись.

Проверка DOM не подтверждает визуальную геометрию и отображение в реальном браузере. Браузерное открытие локальных файлов через доступный инструмент заблокировано его политикой; браузерные скриншоты не получены.
