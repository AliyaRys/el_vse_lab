# Библиотека компонентов лаборатории ВСЭ

Первый набор компонентов выделен из макета **login**. Каталог и страница входа используют один и тот же код.

## Что посмотреть сначала

Откройте в левом меню **Вход → Экран входа → Полный экран**. Затем посмотрите отдельные элементы в согласованном порядке:

1. **Поле ввода** — обычное, заполненное, пароль, ошибка, недоступное, с пояснением, длинной подписью и в фокусе.
2. **Кнопка** — оформление входа, вариант без иконки, ожидание, недоступное состояние, длинная подпись и фокус.
3. **Ссылка** — восстановление пароля, длинная подпись и фокус.
4. **Форма входа** — композиция общих компонентов с ошибками и ожиданием.
5. **Экран входа** — всё вместе, в том числе на узком экране.

## Как проверить компонент

Выберите пример в левом меню. В панели **Controls** можно менять доступные параметры: подпись, ошибку, недоступность и другие настройки. Страница **Docs** у каждого компонента содержит его описание и варианты.

Наведите мышь на элемент, чтобы проверить наведение. Нажмите Tab, чтобы проверить клавиатурный фокус. Отдельные примеры «В фокусе» включают его автоматически.

Для просмотра телефона используйте пример «Узкий экран» или инструмент выбора размера в верхней панели. Чтобы вернуться к ширине окна, выберите адаптивный размер.

## Проверка формы

В обычной форме нажмите «Войти» с пустыми полями: появятся ошибки и фокус на первом поле. Затем введите фиктивные данные и отправьте форму снова.

**В Storybook всё демонстрационное:** ожидание и отказ имитируются, переходы не выполняются, настоящая авторизация не подключена. В самом `login.html` сохранён демонстрационный переход на страницу журнала.

## Как библиотека связана с макетом

Общий код находится в `components/auth/`. HTML подключает обычные скрипты, а Storybook импортирует те же файлы. Изменение общего компонента влияет на оба представления.

Остальные макеты пока используют прежнюю реализацию. Следующие экраны нужно переводить на библиотеку постепенно, сохраняя их согласованное оформление.

## Как открыть каталог снова

Попросите Codex: «Запусти Storybook и открой экран входа».

Или выполните в PowerShell:

```powershell
cd C:\journal
npm.cmd run storybook
```

Оставьте терминал открытым и перейдите на `http://localhost:6006`.

Подробная инструкция — `STORYBOOK.md`; API компонентов — `components/auth/README.md`; правила оформления — `DESIGN.md`, поведение — `UX-CONTRACT.md`.
