# 07. Активация учётной записи — ТЗ отменено

Решение владельца продукта: активация учётной записи и приглашения по email отменены. Администратор сам задаёт пользователю логин и пароль при создании записи ([02](02-user-create.md)), пользователь входит по ним; созданная запись сразу «Активен».

Реализация экрана и его компоненты в `components/auth/` и макет `account-activation.html` удалены из демонстрации. Демонстрационная политика пароля `VseAuth.demoPasswordPolicy` сохранена и используется формами администратора ([02](02-user-create.md)). Состояние «Учётная запись заблокирована» описано отдельным ТЗ [10](10-account-blocked.md).
